School Database SQL

SQLite schema, sample data, and queries for users, notes, and tags.

Entering data: Run the CREATE TABLE statements first, then the INSERT statements. Add a user, create notes with that user's ID, add tags, then link note and tag IDs in note_tags. This static page displays SQL; it does not itself save data or connect to a database.

Tables and relationships

Each note belongs to one user, so users and notes have a one-to-many relationship. Notes and tags have a many-to-many relationship represented by note_tags. Its composite primary key prevents duplicate note/tag links. Cascading foreign keys remove links when a note or tag is deleted.

PRAGMA foreign_keys = ON;

CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT NOT NULL UNIQUE
);

CREATE TABLE notes (
    id INTEGER PRIMARY KEY,
    user_id INTEGER NOT NULL,
    text TEXT NOT NULL,
    created_at TEXT NOT NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE TABLE tags (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL UNIQUE
);

CREATE TABLE note_tags (
    note_id INTEGER NOT NULL,
    tag_id INTEGER NOT NULL,
    PRIMARY KEY (note_id, tag_id),
    FOREIGN KEY (note_id) REFERENCES notes(id) ON DELETE CASCADE,
    FOREIGN KEY (tag_id) REFERENCES tags(id) ON DELETE CASCADE
);

-- Amina's notes, newest first.
SELECT notes.text, notes.created_at
FROM notes
JOIN users ON users.id = notes.user_id
WHERE users.name = 'Amina'
ORDER BY notes.created_at DESC;

-- All notes tagged urgent.
SELECT notes.text
FROM notes
JOIN note_tags ON note_tags.note_id = notes.id
JOIN tags ON tags.id = note_tags.tag_id
WHERE tags.name = 'urgent';

-- Number of notes for each user, including users with no notes.
SELECT users.name, COUNT(notes.id) AS note_count
FROM users
LEFT JOIN notes ON notes.user_id = users.id
GROUP BY users.id, users.name
ORDER BY users.id;

-- Indexes for Amina's newest-first notes and lookup of note links by tag.
CREATE INDEX idx_notes_user_created ON notes(user_id, created_at DESC);
CREATE INDEX idx_note_tags_tag_note ON note_tags(tag_id, note_id);

Index choices

  • notes(user_id, created_at DESC) helps find a user's notes newest first.
  • note_tags(tag_id, note_id) helps find notes for a tag. The primary key starts with note_id, supporting the reverse join direction.
  • Primary keys and UNIQUE constraints already index IDs, user emails, and tag names.
